**gate 三态**（与 V0 治理对齐）：

| 态 | 含义 | 能否 flip 下游 flag |
|---|---|---|
| **scaffold** | 模块/单测/smoke 通过 | 否 |
| **partial** | 某信号 `_v1_gate --signals k` exit 0 | 否（非 authoritative） |
| **merge PASS** | `_v1_gate --merge` 三 partial 全 ok，exit 0 | 才允许宣告 V1 PASS / 讨论 V4 |

**Phase 1 vs Phase 2**（V1-③ 专用；其它信号无 proxy PASS）：

- **Phase 1（proxy）**：GT 监督 proxy（如 GT depth+vel τ）；可 emit partial，**不得** `--merge` 宣告 V1 PASS。
- **Phase 2（authoritative）**：产品路径（`DepthMinPredictor` D̂ + FOE τ + 可选 planner）；三信号全 Phase 2 才 merge。

#### 1.2.1 V1-① 碰撞率下降（4090 / H100→4090）

**意图**：V1 双通道罩（`DepthTauShield` + τ + 可选 planner）相对 V0 同 harness **更少撞**。

| 字段 | 定义 |
|---|---|
| **harness** | 与 V0 ②④ 相同：`v0_rollout_eval` obstacle-facing scan + `HeuristicPolicy`；`rollout-dataset=dataset_v0_headon_*` |
| **V0 臂** | `ThresholdSafetyShield` + `DepthMinPredictor`（仅 D̂ 路） |
| **V1 臂** | `DepthTauShield` + `DepthMinPredictor` + `TauPredictor`（Phase 2 加 FOE τ）；`planner.enable` 按 Phase 2 规格 |
| **`coll_rate`** | episode-level：**任一 step** `next_obs.collided=True` 则该 ep 计 1；`coll_rate = (#碰撞 ep) / n` |
| **基线** | 同 starts、同 n，先跑 V0 臂得 `coll_rate_v0`（或引用 frozen V0 partial_24 同协议复测值） |
| **判据** | `coll_rate_v1 ≤ coll_rate_v0 × (1 − δ)`，**δ = 0.20** |
| **scan 失败** | 0 accepted starts → **FAIL closed**（reason=`no obstacle-facing starts`），不得用 open-loop 替代 |

**首跑注记（2026-08-15）**：spawn_collision 回归导致 scan 0/8 — ① blocked 于 harness，非 δ 问题；修复后复跑。

#### 1.2.2 V1-② 多步想象保真（H100 离线）

**意图**：WM 在 H=15 开环跟踪真实轨迹，且相对 V1a 地板 **更强**（fidelity，非仅 non-divergence）。

**前置（V1a 地板，已 PASS 可引用，不重复计为 ②）**：

- `_wm_train_validate`：learning + H=15 latent norm 有界（如 max norm ≤ 25，沿用 V0 B 项口径）

**② 主判据**（`_wm_fidelity_eval` / `wm_eval.fidelity_verdict` + recon growth）：

| 子项 | PASS |
|---|---|
| **reward** | `reward_beat_frac ≥ 0.80` 且 1-step MAE < constant baseline 且 `reward_growth_ok` |
| **done** | `done_acc ≥ done_majority_acc` |
| **recon** | multi-step decoder recon `recon_growth_ok=true` |
| **latent** | `latent_norm_max ≤ 25`（与 V1a 地板一致；超标 FAIL） |
| **p_coll / coll** | 见下 **N/A 规则** |

**p_coll AUROC — N/A 规则**（避免 NaN 误判）：

| held-out 碰撞轨数 `coll_traj_pos` | `coll_ok` |
|---|---|
| **≥ 3** | 常规定义：`coll_auroc ≥ 0.65` |
| **1–2** | **N/A** — partial 记 `coll_ok=null`，**不单独 FAIL**；② 由 reward+done+recon+latent 决定 |
| **0** | **N/A** — 同上；须在 merge JSON 注明 `coll_insufficient=true`，并 **增采含碰撞 held-out** 后复跑 |

**② overall**：`reward_ok ∧ done_ok ∧ recon_growth_ok ∧ latent_ok ∧ (coll_ok ≠ false)`（`coll_ok` 为 null 时视为满足）。

**首跑注记**：`wm_step_5000` held-out 12 ep、`coll_traj_pos=0` → `coll_ok` 应为 **N/A** 非 FAIL；`reward_beat_frac=0.53` → ② 仍 FAIL。

#### 1.2.3 V1-③ τ / D̂ 双通道独立

**意图**：τ 路与 D̂ 路触发集合 **不完全重合**（缓解共因失效）。

##### Phase 1 — proxy（仅调试，非 authoritative）

| 字段 | 值 |
|---|---|
| **τ** | GT depth + closing-vel → `tau_pred` |
| **D̂** | GT forward min depth（或 `forward_min_depth` on GT） |
| **阈值** | 与 shield 一致：`min_depth_m=1.5`，`min_tau_s=1.0` |
| **判据** | `both_fail_frac ≤ 0.35` 且 (`depth_only_frac>0` 或 `tau_only_frac>0`) |
| **merge** | **禁止** 仅凭 Phase 1 ③ 宣告 V1 PASS |

##### Phase 2 — authoritative（gate 必选）

| 路 | 输入 | PASS 附加条件 |
|---|---|---|
| **D̂** | `DepthMinPredictor` → `depth_min_pred` | 在 r60 留出帧上，D̂-trigger 与 GT-depth-trigger 的 `both_fail_frac` 仍 ≤ 0.35；**D̂ 路 median reproj 沿用 V0 ③ ≤ 0.25**（同 ckpt） |
| **τ** | FOE 散度头 → `tau_pred`（**禁** GT depth 推理） | τ 独立误差：\|τ_pred − τ_gt\| MAE ≤ **2.0 s**（导航带帧）；`tau_only_frac ≥ 0.005` |
| **both-fail** | 公开 `both_fail_indices`（≤32 条） | `both_fail_frac ≤ 0.20`（Phase 2 严于 proxy 0.35） |

**首跑注记**：Phase 1 ③ PASS（`both_fail_frac=0.002`）**不计** authoritative。

#### 1.2.4 信号总表

| 信号 | 位置 | Phase 2 判据（摘要） |
|---|---|---|
| **V1-①** | H100→4090 | `coll_rate_v1 ≤ 0.8 × coll_rate_v0`，n=8 |
| **V1-②** | H100 | fidelity 四件套 + latent≤25；coll AUROC≥0.65 或 N/A |
| **V1-③** | H100 (+4090 对照) | D̂_pred + FOE τ；both_fail≤0.20；V0③ reproj 仍过 |

Horizon 恒 ≤ `MAX_IMAGINATION_HORIZON=15`；抬到 16 须显式改 cap + re-freeze。

## 2. V4 设计

### 2.1 目标（母本 §7 V4）

在 **已验证 WM + V1 安全双通道** 上，于想象中训练 actor-critic，用真环境 rollout 校正模型误差；**超越 BC / 启发式天花板**（发现步数↓、到达率↑）。

### 2.2 前置条件（全部满足才讨论 flip `enable_policy_update`）

- [x] V0 四信号 merge PASS
- [ ] V1b 三信号 merge PASS
- [ ] `imagination.py` H=15 开环已证明非发散（V1-②）
- [ ] 4090 Fork A 仍绿（depth_rate ≥ step_hz）

### 2.3 架构（对齐 DreamerV3，见 [dreamerv3-alignment-optim.md](2026-08-04-dreamerv3-alignment-optim.md) §2.5）

```
collect (4090) → buffer → [V1 WM update] → imagine(batch, H≤15) → λ-return AC update → deploy smoke
```

| 组件 | 现状 | V4 交付 |
|---|---|---|
| `imagine()` | ✅ numpy 批想象 | 接入 torch RSSM `step` |
| `corrector._update_policy()` | stub，返回 `trajectories produced` | **λ-return + REINFORCE + 熵正则 + value stop-grad**（DreamerV3 原样，**不用 PPO**） |
| `imagination_policy` | 占位 / HeuristicPolicy | Actor 网络 `act_latent(z)` |
| Critic | 无 | Value head on latent |
| 真环境校正 | collector 每 iter 采真轨迹 | 想象 loss + 真 env TD 误差混合（比例待调） |

**插入点**：`corrector.py:176` `# >>> V4 INSERTION POINT: actor_critic.update(rollout) <<<`

### 2.4 V4 过关信号（草案，需 re-freeze）

| 信号 | 内容 | 草案 |
|---|---|---|
| **V4-①** | 到达率 / progress | 对 V3 基线（或 HeuristicPolicy V0 ② 同协议）：`progress ≥ baseline + margin` |
| **V4-②** | 发现步数 | SEARCH 任务上 median steps-to-discovery ↓（V2/V3 任务就绪后评） |
| **V4-③** | 样本效率 | 同等 wall-clock 下优于纯 BC（记录训练步数/真 env 交互数） |
| **V4-④** | 安全不回归 | ④c ratio 仍 ≤ 0.80；碰撞率不高于 V1-① |

**禁止**：V4 训练顺带打开 V2 语义模块或改 V0 §4.1 阈值。
