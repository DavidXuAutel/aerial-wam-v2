## 1. V1 设计

### 1.1 目标（母本 §7 V1）

在 V0 已验证的感知+安全基座上，增加：

1. **[1d] 光流 time-to-contact τ** — FOE + 散度，**独立于 D̂**，写入 `obs.info["tau_pred"]`
2. **短程想象规划** — `imagination.py` 对候选动作序列打分（horizon ≤ 15）
3. **τ/D̂ 双通道安全罩** — `DepthTauShield = D̂ ∪ τ ∪ p_coll`；两路独立触发，缓解共因失效

### 1.2 V1 三个同权过关信号（待 re-freeze 数值表）

| 信号 | 内容 | 评估位置 | 草案判据 |
|---|---|---|---|
| **V1-①** | 碰撞率相对 V0 ↓ | 4090 rollout（与 V0 ②④ 同 harness） | `coll_rate_v1 ≤ coll_rate_v0 × (1 − δ)`，δ 待 re-freeze（建议 0.20 起） |
| **V1-②** | 多步想象保真 | H100 离线（**诚实留出** ckpt，禁 in-sample 失效 wm） | 开环 H=15：`wm_eval.fidelity_verdict`；latent norm 不爆炸；recon/entropy 不塌缩（延续 `_wm_train_validate` B 项） |
| **V1-③** | τ / D̂ **双通道独立**验证 | H100 离线 + 4090 对照 | τ 路：FOE 散度 vs GT 位移独立误差 ≤ 阈值；D̂ 路：沿用 V0 ③ 重投影；**both-fail 集合**公开列举 |

Horizon 恒 ≤ `MAX_IMAGINATION_HORIZON=15`（`imagination.py`）；抬到 16 须显式改 cap + re-freeze。

### 1.3 实现分期

#### Phase V1a — WM 接入 corrector（可先跑，不宣告 V1 PASS）

**资产（已有）**

| 资产 | 路径（H100） |
|---|---|
| 权威 WM ckpt | `wm_ckpt_r60_20260814/wm_step_5000.pt` |
| 训练语料 | `dataset_v0_local_depth_r60_20260814`（51 npz / 48 usable） |
| 深度 ckpt | `depth_ckpt_da3_r60_20260814/depth_step_2000_da3_ft_head.pt` |

**步骤**

1. H100：`_wm_train_validate` 在 **r60 语料**上复验 learning + non-divergence（H=15，禁 `--allow-v0-desync`）
2. 通过后再 `--steps 5000` 长训或直接从 r60 ckpt warm-start（**禁止** warm-start 失效 `wm_step_5000.pt`）
3. 改 yaml（仅 V1a，仍不算 V1b PASS）：
   ```yaml
   dynamics:
     kind: torch
   corrector:
     enable_wm_update: true
   ```
4. `train_rl` smoke：`corrector.iterations=3`，日志须 `wm=updated` 非 `skipped`
5. 新增 **`_v1_gate.py`**（或扩展 `_v0_gate` 的 V1 模式）：只评 V1-②，emit `v1_partial_wm.json`

**回滚**：`kind: stub`、`enable_wm_update: false` — stub 环始终可跑。

#### Phase V1b — τ + 想象规划 + 双通道罩（完整 V1）

| 模块 | 文件（计划） | 职责 |
|---|---|---|
| τ 头 | `tau_predictor.py`（新） | RGB/光流 → τ；监督：GT depth + 相邻帧位移 → FOE 散度伪标签 |
| 双通道罩 | `safety.py` 扩展 | `DepthTauShield`：`min(D̂, τ) < threshold` 独立 OR；`p_coll` 第三路 |
| 想象规划器 | `imagination.py` + `planner.py`（新） | 编码 z₀ → 滚动 K 条候选动作轨 → WM 打分 → argmax |
| V1 gate | `_v1_gate.py` | 三信号 merge；exit 0 才允许进入 V4 设计评审 |

**数据**：V1 τ 监督可复用 r60 depth 语料；碰撞/接近窗增采可选 `dataset_v0_headon_*` 扩展。

**P0b 依赖**：shield 若切到 `predict_cones()`（`V0_GATE_STATUS` C1），V1 双通道罩应消费 **锥 + τ**，而非仅 forward min。

## 2. V4 设计

### 2.1 目标（母本 §7 V4）

在 **已验证 WM + V1 安全双通道** 上，于想象中训练 actor-critic，用真环境 rollout 校正模型误差；**超越 BC / 启发式天花板**（发现步数↓、到达率↑）。

### 2.2 前置条件（全部满足才讨论 flip `enable_policy_update`）

- [x] V0 四信号 merge PASS
- [ ] V1b 三信号 merge PASS
- [ ] `imagination.py` H=15 开环已证明非发散（V1-②）
- [ ] 4090 Fork A 仍绿（depth_rate ≥ step_hz）

### 2.3 架构（对齐 DreamerV3，见 [dreamerv3-alignment-optim.md](2026-08-04-dreamerv3-alignment-optim.md) §2.5）

```
collect (4090) → buffer → [V1 WM update] → imagine(batch, H≤15) → λ-return AC update → deploy smoke
```

| 组件 | 现状 | V4 交付 |
|---|---|---|
| `imagine()` | ✅ numpy 批想象 | 接入 torch RSSM `step` |
| `corrector._update_policy()` | stub，返回 `trajectories produced` | **λ-return + REINFORCE + 熵正则 + value stop-grad**（DreamerV3 原样，**不用 PPO**） |
| `imagination_policy` | 占位 / HeuristicPolicy | Actor 网络 `act_latent(z)` |
| Critic | 无 | Value head on latent |
| 真环境校正 | collector 每 iter 采真轨迹 | 想象 loss + 真 env TD 误差混合（比例待调） |

**插入点**：`corrector.py:176` `# >>> V4 INSERTION POINT: actor_critic.update(rollout) <<<`

### 2.4 V4 过关信号（草案，需 re-freeze）

| 信号 | 内容 | 草案 |
|---|---|---|
| **V4-①** | 到达率 / progress | 对 V3 基线（或 HeuristicPolicy V0 ② 同协议）：`progress ≥ baseline + margin` |
| **V4-②** | 发现步数 | SEARCH 任务上 median steps-to-discovery ↓（V2/V3 任务就绪后评） |
| **V4-③** | 样本效率 | 同等 wall-clock 下优于纯 BC（记录训练步数/真 env 交互数） |
| **V4-④** | 安全不回归 | ④c ratio 仍 ≤ 0.80；碰撞率不高于 V1-① |

**禁止**：V4 训练顺带打开 V2 语义模块或改 V0 §4.1 阈值。

### 2.5 配置 flip（仅 V4 PASS 后）

```yaml
corrector:
  enable_policy_update: true   # GATE V4
imagination:
  horizon: 15                  # 先满 cap；16 需改 MAX_IMAGINATION_HORIZON
```

`w_maneuver` curriculum（progress/SR 过阈再拉起）与 V4 同步启用（§2.4 dreamerv3-alignment §2.4）。

### 2.6 消融（论文向，P2）

- **消融 A**：在线想象打分 vs 蒸馏纯前馈 actor（部署零想象）
- **消融 B**：imagination RL 是否自发产生主动搜索/注视（无需显式 frontier 奖励）

### 2.7 V4 里程碑顺序

1. V1b PASS → 2. Actor/Critic 模块 + 单测（mock dynamics）→ 3. H100 纯想象训练 smoke → 4. 4090 闭环 corrector 3 iter → 5. 任务级 eval → 6. `_v4_gate` merge → 7. flip `enable_policy_update`
