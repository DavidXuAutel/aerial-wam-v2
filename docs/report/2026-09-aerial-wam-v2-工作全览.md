## 一、项目背景与目标

本项目面向**无人机纯视觉自主导航**场景，以摄像头为主传感器，结合 IMU 与高度信息，构建世界动作模型（WAM），实现「感知—决策—飞行」闭环。技术路线为：**仿真验证 → 模型训练 → 真机部署**。

项目于 **2026 年 8 月 14 日** 从既有机器人控制项目中独立拆分，成立专用代码仓库，聚焦空中导航方向攻关。WAM 的「RGB 感知 + 潜空间世界模型 + 想象规划 + 安全护盾」架构本身与载体无关，**空中导航验收完成后，下一阶段的自然延伸是将同一套模型栈迁移至地面机器人平台**（详见第七章）。

## 二、核心技术原理

### （一）问题定义与约束

无人机在未知、部分可观环境中执行导航任务，本质上是一个**部分可观测马尔可夫决策过程（POMDP）**：目标位置事先未知，观测局部、目标可能长期不可见，需要记忆与多步决策，而非单帧反应映射。


| 能力     | 含义                     |
| ------ | ---------------------- |
| 自主寻找目标 | 目标位置未知，需主动探索直至视觉命中     |
| 航迹规划   | 在记忆与预测之上选择多步子目标与短程动作序列 |
| 主动避障   | 在碰撞发生前规避，含对即将进入危险构型的预判 |
| 导航到达   | 命中后接近目标并稳定终止           |


**传感硬约束**：外感知仅一颗**单目 RGB 相机**；飞控本体感知（IMU、姿态、气压/GPS 高度）为平台已有信号，纳入但不违反纯视觉约束。禁止依赖深度相机、双目硬件或全局 SLAM（回环校正后的全局度量地图）。

### （二）总体架构

系统采用「感知—记忆—预测—决策—安全」分层闭环：

### （三）七大设计原则

1. **纯视觉外感知闭环**：几何由学习预测 + 本体感知锚定，而非深度硬件或全局 SLAM。
2. **多柱几何，拒绝单柱**：尺度靠 VIO/IMU、独立安全靠 flow-ToC、长程靠拓扑——不把避障与规划全压在深度预测一根柱子上，避免共因失效。
3. **分层决策**：长程用拓扑（去哪一片该去的地方）；短程用世界模型想象 + 预测深度 + 局部度量代价（怎么飞过去且不撞）。
4. **世界模型进入控制回路**：用于短程 rollout、碰撞预判与基于想象的强化学习；像素级视频预测仅用于预训练与蒸馏，不在线逐步像素规划。
5. **模式可观测**：`SEARCH` / `NAV` / `DONE` 三模式可日志、可门禁、可调试。
6. **安全硬约束压过学习策略，且触发信号冗余**：保守动作不交给纯价值涌现；安全罩至少有一路（flow-ToC）独立于深度预测。
7. **分段可验证**：每阶段有可独立验收的子系统；未过关不叠加下一阶段。

### （四）安全护盾机制

安全罩是系统的**最后一道硬约束**，优先级高于规划与学习策略：

- **触发源**：`D̂`（不确定度膨胀后） **∪** `τ`（光流碰撞时间，独立于 `D̂`） **∪** `p_coll`（世界模型碰撞风险预测）
- **任一超阈** → 刹停 / 有界后退 / 悬停等保守动作
- **设计意图**：即使深度预测在纹理缺失、透明物体或强反光下失效，`τ` 通道仍可提供独立的安全触发，缓解「安全罩与世界模型共用同一深度信号」的共因失效风险

### （五）Phase-2 导航决策模式

户外长距离导航（Phase-2）采用**目标导向 + 场景意图**决策模式，而非传统轨迹跟踪：

- **输入**：远处目标点 G（主尺度 200—500 m）+ 当前眼前场景
- **无预置航迹**：不依赖标注折线或滚动参考轨迹
- **决策流程**：WAM 外环根据目标 G 与场景生成近距意图 c* → Phase-1 快执行层落地 → 安全罩兜底 → 到达判据 ‖p−G‖ ≤ 3 m
- **全局参考规划**：子目标生成、场景意图规划与全栈安全护盾协同工作

### （六）训练与验证分期

系统按能力阶梯逐步叠加，每档有可独立验收的门禁信号：


| 阶段  | 核心内容                            | 过关信号                          |
| --- | ------------------------------- | ----------------------------- |
| V0  | RGB 编码 + 多帧深度头 + VIO            | 非塌缩、接近量上升、深度尺度与 VIO 一致、近障护盾生效 |
| V1  | 快世界模型 + 短程想象规划 + τ/D̂ 双通道安全罩    | 碰撞率下降、多步 rollout 达标、双通道独立验证   |
| V2  | 混合记忆 + 探索策略                     | 覆盖率优于随机基线                     |
| V3  | 语义 grounding，打通 SEARCH→NAV→DONE | 发现率与到达率形成基线                   |
| V4  | 世界模型想象中做 RL + 真环境 rollout 校正    | 发现步数与到达率超越行为克隆天花板             |


**数据原则**：惯性、稠密感知与碰撞信号从仿真器 rollout 获取（非静态数据集）；推理期策略仅消费 RGB + proprio4，深度/IMU 等特权信号仅用于训练监督，不泄漏进策略计算图。

## 七、未来拓展：地面机器人平台

空中 Phase-2/Phase-3 验收完成后，项目组计划将 **同一套 WAM 模型栈** 扩展至**地面移动机器人**（轮式/履带底盘、RoboMaster 竞赛平台等），形成「空中 + 地面」统一的具身导航能力。本项目代码源自 `robomaster-tt-control` 生态，与地面机器人团队在硬件、仿真与部署链路上具备天然衔接基础。

### 7.1 迁移动机与可行性


| 维度   | 空中（当前）                                                    | 地面（规划）                                              |
| ---- | --------------------------------------------------------- | --------------------------------------------------- |
| 外感知  | 单目 RGB 224×224                                            | **同口径**——前向/胸前相机，仍遵守纯视觉硬约束                          |
| 决策核心 | TorchRSSM（1536-D）+ LatentActorCritic + ImaginationPlanner | **直接复用**，仅需域适配微调                                    |
| 几何感知 | DA3 深度头 + FOE 光流 τ                                        | **复用架构**；在地面视角与障碍高度上重训/微调                           |
| 安全护盾 | ThreeZone + D̂ ∪ τ ∪ p_coll                               | **复用逻辑**；速度线、触发阈值按地面动力学重标定                          |
| 本体感知 | IMU + 气压/GPS 高度                                           | 轮速里程计 / IMU + **平面约束**（z 固定或缓变）                     |
| 动作空间 | `(dx, dy, dz, dyaw)` 4-D 体坐标                              | `(dx, dy, 0, dyaw)` 或 `(v_x, v_y, ω_yaw)`，**约束竖直维** |


核心判断：**模型层（RSSM、π、深度头、规划器）可跨平台复用**；需改造的主要是环境桥接层（仿真器/底盘驱动）与动作执行接口，而非重新设计世界模型架构。

| 空–地协同（远期） | 无人机侦察 + 地面机器人抵近     | 统一 WAM 权重 + 分平台 env 适配层                |


**候选硬件平台**：RoboMaster 标准步兵/哨兵底盘（与源码生态同源）、通用轮式 UGV（Orin 伴飞 + USB 相机）、室内研发用小型差速底盘。

### 7.5 风险与边界

- **视角差异**：地面相机高度低（~0.3–1.0 m），障碍几何与天空/地面分界不同于空中，深度头需专项微调，不可直接沿用空中 AbsRel 门禁数值。
- **动力学差异**：地面机器人无竖直自由度，需硬性约束 `dz=0` 并在训练/评测中统一，避免空中策略输出无意义爬升指令。
- **控制频率**：地面底盘通常 10–50 Hz，高于空中 5 Hz，需重标 `step_hz` 与 `body_delta_limits`，并重跑安全罩反应余量验证。
- **仿真底座**：地面仿真器需确认能提供 RGB + 稠密深度 + 碰撞 + 里程计 GT（类比空中 Fork A GO/NO-GO 核查），达标后方可启动 G0。

## 八、结论

Aerial WAM v2 项目在一个半月内完成了从**技术验证 → 户外导航验收 → 真机系统落地**的关键跨越。户外纯视觉导航已通过正式验收，真机硬件软件一体化部署已到位，户外室内统一模型与室内精飞、视觉跟踪等方向同步推进。项目整体处于**由仿真向真机转化、由单场景向多场景扩展**的阶段；**下一阶段将把已验证的 WAM 模型栈迁移至地面机器人平台**，形成空中—地面统一的具身视觉导航能力，具备持续迭代和跨平台工程化推进的基础。
