## 2. 「类 MPC」全局层具体指什么

与控制里 MPC 对齐的是 **滚动时域 + 反馈重优化**，不必第一步就上完整非线性 MPC 求解器。

### 2.1 最小可实现（第一版全局）

每 ΔT（或每 N 局步）：

1. 状态：当前 \(p,\psi\)，最终 G，可行域 \(\mathcal{F}\)（占据 / 深度锥近似）  
2. 在短视界内生成或修正参考：例如  
   - 朝 G 的可行走廊内短折线；或  
   - 在旧 \(P_{ref}\) 上重投影 + 前方重采样；或  
   - 简单采样优化（代价：到 G 的进度、曲率、净空、与上一拍一致性）  
3. 输出更新后的 \(P_{ref}\)（或直接输出下一预瞄生成参数）  
4. **不**要求局部在 ΔT 内「走完」\(P_{ref}\)

### 2.2 与静 A\* 主航道的差别

| | 静折线跟踪（现状偏置） | 动态全局（本方案） |
|--|------------------------|-------------------|
| \(P\) | 任务开始固定 | **滚动刷新** |
| 反馈 | 多用于 CTE 缩 R | **进入重规划代价** |
| 失败 | 易锁在坏参考上 | 无进展 → 触发重规划 |
| 到点 | 易被弧长 Prog 冒充 | **只认 ‖p−G‖** |

现有 `AdaptiveSubgoal` 可视为：**在固定 \(P_{global}\) 上的局部预瞄**。本方案把 **\(P\) 本身** 升为滚动量；预瞄仍是 carrot 族（中间不到）。

### 2.3 文献位置（佐证层级，非实现绑定）

- **局部预瞄不到点**：Carrot chasing、Pure Pursuit（Coulter 1992）、几何 path following 综述  
- **滚动全局**：MPC path planning / receding-horizon motion planning；分层「planner + tracker」  
- **本栈特化**：tracker = 已证 Phase-1 WAM；planner = 新全局滚动层

## 3. 三个定点（按本方案）

| 点 | 定论 |
|----|------|
| **「段/线」多长** | 全局视界 \(H_g\)（时间或米）与局部 lookahead δ **分开**。δ 仍 ~15–40 m（Phase-1 尺度）。\(H_g\) 可更长（例如数十米～百米级参考），但 **不塞进 π**。 |

## 8. 可行性审查（诚实论证 · 2026-09-02）

### 8.1 总判

| 问 | 答 |
|----|-----|
| 架构方向对不对？ | **对。** 分层 planner（滚动）+ tracker（Phase-1）是成熟范式；局部复用阶段 1 是本项目最强资产。 |
| 现在能否按全文落地并承诺 SR≥80%？ | **不能。** 全局滚动层在本栈 **尚未存在**；可飞约束、重规划触发、与 π 的目标跳动兼容性都未证。 |
| 诚实定位 | **条件可行**：P0 做「轻量滚动参考」工程可行；完整非线性 MPC 全局 **另价、另证**；且 **救不了局部 π 失效（R05）**。 |

### 8.2 为什么方向可行（支持证据）

1. **文献与工程惯例**：recoding-horizon / MPC 规划 + 几何预瞄跟踪（carrot / Pure Pursuit）是标准分层；中间预瞄不到点与方案一致。  
2. **本仓库已有半套**：固定 `P_global` + `AdaptiveSubgoal` 已是「全局参考 + 局部预瞄」；差的是全局 **不滚动、反馈弱**。升格路径短——改全局层，不必重造 π。  
3. **阶段 1 已证局部合同**：短距 `g_rel` + 短想象到点高成功率；方案明确 **不把远 G / 长 H 塞进 π**，避免再犯 F2。  
4. **验收口径可纠偏**：停机只认 `‖p−G‖`，直接针对回锚「Prog≈1 且 d_min≈60」的虚高问题（度量层立即有意义，即使第一版全局很笨）。

### 8.3 为什么不能过度承诺（否证 / 风险）

1. **「类 MPC」易被读成「已有 MPC」**  
   真 MPC（动力学约束 + 长时域非凸优化 @ 5–10 Hz）与「每秒重采样一条短折线」差一个数量级。方案写的是前者精神、后者 P0——**P0 可行；全文 MPC 未证**。

2. **全局可飞域 \(\mathcal{F}\) 在仿真里也不免费**  
   - 有稠密占据/原 A\* 图：滚动重规划 **可行**（在已知图上重搜或修补）。  
   - 仅深度锥：只能做 **局部可行**，不是真全局；远障碍、绕楼仍盲。  
   回锚用的是 **标注 native 走廊**——动态全局若仍依赖同一张图，则是「图上滚动」；若宣称无图纯视觉全局，**可行性下降一档**。

3. **局部 Phase-1 不是任意 `g_rel` 序列的万用跟踪器**  
   训练分布是相对平滑、偏「朝近目标收敛」的轨迹。若全局每步大幅跳变 c（重规划抖动），π 可能表现为侧漂、怠速或乱扭——**全局越勤，越可能打出局部 OOD**。必须有：参考一致性代价、c 的速率限制、或重规划频率 ≪ step_hz。

4. **对现有失败模式的覆盖不完整**  

   | 失败 | 动态全局是否对症？ |
   |------|-------------------|
   | Prog 虚高 | **是（度量）**：改停机/进度定义即可，甚至先于全局滚动 |
   | F12 超时、d_min~60、绕飞 | **部分**：更好的参考/重规划可能帮；也可能仍是局部跟踪差或时限不够 |
   | R05 yaw 死 / idle | **否**：局部不动时刷新 P_ref **无效**；须分诊局部 |
   | 终段不进 3 m | **部分**：最后 δ 内令 c→G 是预瞄层技巧，不必整机 MPC |

5. **算力与频率**  
   局部 5 Hz 已满载 AirSim/GPU 时，全局若同频重优化会挤实时。可行默认：**全局 1 Hz 或事件触发**；局部每步只取预瞄。

6. **与「视距 300–500 m」无关**  
   滚动全局仍只优化短视界参考；远程可达性靠 **多次滚动 + 地图/走廊**，不是一次看清 500 m。方案若被理解成「全局想象 500 m」，则 **不可行**。

### 8.4 可行性分层（建议对外口径）

| 层级 | 内容 | 可行性 | 前置 |
|------|------|--------|------|
| **L0 度量** | 主指标用 `‖p−G‖` / 真接近，不用弧长 Prog 冒充到点 | **高 · 立刻** | 无 |
| **L1 预瞄加固** | 固定或慢变 P 上，按飞行反馈调 δ、无进展缩 R/重锚投影 | **高** | V1 分诊 |
| **L2 滚动全局 P0** | 周期/事件在 **已知 \(\mathcal{F}\)** 上重生成短 `P_ref` + 一致性约束 | **中高** | L0+L1，DECLARE |
| **L3 真 MPC 全局** | 显式动力学+多约束优化 | **中长期** | L2 稳 + 算力 |
| **L4 无图远距全局** | 仅 RGB 滚出 300–500 m | **低（当前）** | 另线 |

**结论句：** 方案作为 **L0–L2 路线图可行且应对准主航道**；作为「上了 MPC 就过 Phase-2 门」**不可行叙事**。

### 8.5 必须先成立的假设（否则方案空转）

1. 局部在「慢变、尺度正确的 c」下仍大致会朝 c 运动（非 R05 式全局怠速）。  
2. 仿真全局重规划有权使用与评测一致的 \(\mathcal{F}\)（或明确降级为深度局部）。  
3. 重规划频率与 c 平滑使 `g_rel` 不系统性 OOD。  
4. 验收去掉 Prog 造假通道。  

V1 的任务就是用数据打 1；D0 签字要写清 2。

### 8.6 审查建议（给决策）

- **采纳**分层合同与「局部=Phase-1、中间不到点、只认 G」。  
- **降级承诺**：对外称「滚动全局参考（MPC 风格）」，慎称「已上 MPC」。  
- **执行序**：L0 度量 → V1 分诊 → L1 → L2 P0；R05 局部专项并行，不塞进全局第一刀。  
- **暂缓**：无图 500 m、加长局部想象当全局、F15/assist 混进本方案。
