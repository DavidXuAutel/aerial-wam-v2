## 0. 问什么

K-min（B-1）已证：D̂ 侧 min 滤波 **压不了 consec**。  
B-2 候选 = **触发侧 engage/release 滞回**（控制律允许改；本 Phase 只做离线同构打分）。

**与现行部署 latch 的区别**：`ThresholdSafetyShield` 已是 **整局 latch**（一触永 override）。本扫描的滞回是 **D̂ 通道上的 engage/release**，用于回答：「若 ⓪d 的 miss 按滞回后的触发量计，consec 能否 &lt;2」。**不是**把整局 latch 套进 ⓪d（那会把指标洗成无意义）。

## 1. 滞回定义（冻结本扫描）

每 episode 因果：

```
engaged ← false
for each frame (D̂ = D̂_fwd 或 D̂_fov，与现 ⓪d/⓪f 几何一致):
  if engaged:
    if D̂ ≥ release: engaged ← false
  else:
    if D̂ ≤ trigger: engaged ← true
  triggered ← engaged
```

- `trigger = 3.0`（与 gate 同）
- `release = trigger + δ`，扫 **δ ∈ {0, 0.25, 0.5, 1.0, 1.5, 2.0}**
- **δ=0**：近似现行瞬时阈值（基线）
- ⓪d miss := `(GT_fwd ≤ trigger) ∧ ¬triggered`
- ⓪f(3) 诊断误触 := 在 clearance bin 上 `P(triggered)`（替代 `P(D̂ < trigger)`）

**不**改 ⓪a/⓪c 像素 AbsRel；**不**改 yaml / shield 代码。

### 裁定

1. **全 δ 两片 `consec ≡ 2`** ⇒ Phase C **不可解**（与 B-1 K-min 同型）。  
2. rate 可随 δ 下降；误触/`lo` 随 δ **变差** ⇒ 加大滞回只会买 rate、买不来 consec，还抬假触发。  
3. **机制读法**：consec=2 段是**连续过读、中间没有一次 `D̂≤trigger`** ⇒ engage **从未武装**，release 窗无效。滞回帮的是「先触后抖」；帮不了「连漏未触」。  
4. **不升格 B**（不改 shield、不改 ⓪d 默认口径）。  
5. **下一路径**：`#26`/`5ao`（τ 触发迁移，待签）或感知声明（须含 ①d 锚）；**不是**再扫更大 δ。
