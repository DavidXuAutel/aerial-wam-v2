## 1. (b) 的确切含义（先纠一个普遍误解）

**τ 不是新通道，它早已在部署罩里。** `DepthTauShield._breached`（`safety.py:96-107`）与 `_channels_breached`（`:162-176`）是三通道 **OR**：

```
d_hat = obs.info["depth_min_pred"] < min_depth_m   →  breach
tau   = obs.info["tau_pred"]       < min_tau_s     →  breach
p_coll= wm_out.p_coll              > max_p_coll    →  breach
```

⇒ **(b) 在实现上 = 把 `d_hat` 那条 OR 腿摘掉（或降为只记录），触发交给 `tau`（+ `p_coll`）。** 这是 shield **控制律**改动 —— 红线明许（「shield 控制律是被测系统（可改）」）。

**(b) 自带的一项结构性好处（应登记）**：`TauPredictor.center_frac = 0.5`（`tau_predictor.py:284`）⇒ **τ 天生是前向锥量**；而 `depth_predictor.predict_min`（`:80-88`）是全图单像素 min、无方向过滤。⇒ 迁到 τ **顺带消掉了 P0b 那处「训练/eval 几何 ≠ 部署几何」错配**，不是把它再搬一站。

## 7. τ 的理论边界（如实登记，不许当免费午餐）

**为什么 (b) 理论上有出路**：`τ = D/Ḋ`。由 FoE 光流散度估计时，D 与 V 的**共同尺度约掉** ⇒ τ̂ 不需要度量尺度 ⇒ **不受「单目单帧尺度不可观测」这个 #24 瓶颈的约束**。这是 (b) 与「再训深度头」的本质区别。

**τ 引入的新失效模式（与 D̂ 正交，不是更弱）**：

1. **旋转污染**：纯平移下流场散度才对应 τ；机体偏转/滚转会注入旋转流 ⇒ 须 derotate（需角速度）。未 derotate ⇒ τ̂ 在转弯时失真。
2. **低纹理退化**：Farneback 光流在无纹理白墙上趋于 0 ⇒ **τ̂ → max_tau_s（=60 s，判为安全）**。而「正对白墙」正是 V0 ④ 的失效场景（已记：1.5 m 前墙被 D̂ 读成 ~6.4 m）⇒ **τ 可能在同一批帧上以另一种方式失效** ⇒ 这就是 T-2/T-3 存在的理由：**若 τ-miss 与 D̂-miss 高度重合，(b) 不成立**。
3. **低速盲区**：`v_fwd → 0` ⇒ τ → ∞ ⇒ 永不触发（`min_closing_m_s=0.05` 只是分母下限，不是触发保底）⇒ 慢速贴近墙面无罩。⇒ 纯 τ 罩**在物理上不完备**，最终很可能须 `τ ∪ (D̂ 仅作低速兜底)`；那属另案控制律，**不在本声明范围**，但 T-4 必须先把盲区量化。
4. **τ 只约束「何时刹」，不提供「往哪绕」**：绕行几何仍需深度/占据信息 ⇒ (b) 解决的是**触发**，不解决 planner 的避障几何。S_blocked 已按 (AO) 出局，本轮无冲突；将来重纳时这条会回来。

**一句话**：(b) 把瓶颈从「单目度量尺度不可观测」（**物理不可解**）换成「光流在低纹理/旋转/低速下退化」（**工程可缓解，且有 derotate / 多尺度 / 兜底通道等已知手段**）。这是一次**换到可解侧**的迁移，但换得成不成，由 **T-2 的失效相关性**说话 —— 不由本声明预判。
