# V4 诊断声明：D̂ 时序 K-min 扫描（2026-08-21）

> **性质**：跑前声明（诊断）。**未改任何判据阈值**；`enable_policy_update` 仍 false。  
> **不**把任一 K 升格为过线口径——升格须另声明，且 **训 / eval / 部署三处同 K**。

## 0. 问什么

⓪d 稳固拦路项是 **`consec ≥ 2`**（无分母）。  
单帧 loss 管不了 consec。候选修法：

- **B-1**：D̂ 侧因果 **K 帧 min**（更保守读深 ⇒ 少漏触发、多误触）
- **B-2**：触发侧滞回（shield 控制律，允许改）

本扫描只验 **B-1 是否在老头上可解**。

## 1. 协议

| 项 | 冻结值 |
|----|--------|
| 头 | **老头** `depth_ckpt_da3_r60_20260814/depth_step_2000_da3_ft_head.pt`（部署线；对 `dataset_v0_p45_merged_20260821` **完全未训** ⇒ 全 77 诚实） |
| 语料 | `dataset_v0_p45_merged_20260821` |
| 切片 | **主表** holdout `frac=0.35 seed=0`（与 v3 / #22 同切）；**附表** 全 77 |
| K | `{1,2,3,4,5}`；`K=1` ≡ 现行无滤波基线 |
| 滤波 | **因果**：每 episode 内对标量 `D̂_fwd` / `D̂_fov` 取最近 ≤K 个有限值的 **min**；不足 K 用已有窗 |
| 影响面 | **仅** ⓪d（rate/consec）与 ⓪f(3)（`clearance_sweep` 的 D̂ 误触）；**不**改 ⓪a/⓪c 像素 AbsRel |
| 机 | 4090 或 H100（CUDA eval） |

Harness：`v4_zero_eval --dhat-temporal-min K`（默认 1）；扫描用 `--scan-dhat-temporal-min 1,2,3,4,5`（**一次前向、多 K 复评**）。

## 2. 一次出的三条曲线（每切片各一套）

对每个 K 报告：

1. **consec** = `max_consecutive_miss`
2. **rate** = `p_miss_trigger`（分母 `n_near_forward_frames`）
3. **⓪f(3)** = `suggest_delta.suggested_lo_clearance_m`（诊断；另附近墙 bin 误触便于读）

## 3. 读法（事前写死）

| 结果 | 结论 |
|------|------|
| 某 K：consec **&lt; 2** 且 ⓪f(3) diag `lo` **不劣于 K=1 超过约定裕度**（本诊断只**报数**；是否可接受由人读，**不自动升格**） | 路径可改为「加时序口径」；若要用该 K 过线 ⇒ **另声明 + 三处同 K** |
| 全 K consec 仍 ≥2，或 consec 好但误触明显炸 | consec **超出 D̂ 侧单靠 min 滤波的能力** ⇒ 须走 **B-2 滞回**（或感知重训），本扫描给明确否定 |

**禁止**：看到某 K 好看后静默改默认；禁止只在 eval 开 K、部署不开。

### 6.3 裁定（按 §3 事前表）

1. **全 K 两片 `consec ≡ 2`** ⇒ **B-1（D̂ 侧 K-min）解不了 consec**。  
2. rate：K≥2 可压（全 77 点估计 ≤0.05；主表仍 0.057）；**稳固支点仍是 consec，rate 改善不够过线**。  
3. ⓪f(3)：K↑ ⇒ 近墙误触单调变差；主表 `lo` 5.25→6.0；全 77 在 K≥3 跳到 6.25。  
4. ⇒ **须走 B-2 滞回（控制律）** 或感知重训；**不**把任一 K 升格为过线口径；默认 `--dhat-temporal-min` 仍为 **1**。
