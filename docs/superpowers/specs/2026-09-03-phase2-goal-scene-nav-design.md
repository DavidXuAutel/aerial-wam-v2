## 2. 为何旧路歪了

1. **把脚手架当成产品**：长评测默认 `折线 → carrot → π`，量 Prog/CTE → 诱导「跟线 / 滚动 GT」方案。

3. **能力错配**：Phase-1 是近距到点；被当成 100 m+ 折线跟踪器。  
4. **动态**：标注折线不随场景变；滚动 GT 参考也不看景「改主意」。

旧产物（`GlobalRefPlanner`、 `--rolling-global`、L1 carrot 反馈）→ **降级为对照/水位**，默认 OFF，不再当主航道下一刀。

## 4. 架构（方案 B）

```text
                    G
                    │
        ┌───────────▼───────────┐
        │ Intent / Subgoal 外环  │  周期 ΔT 或事件（挡路、无进展）
        │ 候选 {c_k} + WM/启发式 │  打分：进展·可飞·一致·安全
        └───────────┬───────────┘
                    │ c* （Phase-1 尺度，~10–40 m 量级）
        ┌───────────▼───────────┐
        │ Phase-1 WAM 内环       │  π + 可选短想象 H≪外环
        │ meter g_rel(c*)        │
        └───────────┬───────────┘
                    ▼
                 Shield → step
```

### 4.1 外环：如何「临时画一段」（无准线）

候选来源（P0 可丑，但必须 **不依赖 GT 折线**）：

1. **朝 G 的机体方向扇区**：若干偏航/俯仰上的近距点（固定距离 \(r\)）。  
2. **深度/净空可行**：丢弃前方危险锥内的候选。  
3. **可选**：短动作开环 / WM 滚动终点作为候选。

打分（概念）：  
\(J = -w_g\cdot\mathrm{progress}(G) + w_{coll}\cdot p_{coll} + w_{jump}\cdot\|c-c_{prev}\| + \cdots\)

输出：单一 `c*` → 写入 `goal` / `goal_rel`，供 π 使用。

### 4.2 内环：Phase-1（冻结合同）

- 保持 `step_e` + meter；**不**把远 G 直接塞进 π（除非消融 A）。  
- 短想象仅服务「执行 c*」，不替代外环选路。  
- 罩不变。

### 4.3 与距离尺度（锁定 **200–500 m**）

远距由 **多次外环重选 c*** 叠加，不靠一条长参考线，也不靠把局部想象 H 拉长到公里级。

| 尺度 | 定位（诚实） |
|------|----------------|
| **~100 m** | **已越过的早期水位**；不再作为主目标尺 |
| **200–500 m** | **当前主尺度 / 过门尺**（与既有「视距 300–500 / 跨区 200–500」口径对齐）；仿真可用 GT 位姿代理，须有对应走廊/场景 |
| **~1 km** | 仅远期愿景；须另过定位无漂与评测基建；**不得**用 200–500 成绩宣称 1 km |
| 瓶颈 | 深度/想象只覆盖眼前数十米；扩到 500 m 主要卡外环稳定重选与误差累积，不是「π 一次看清终点」 |
